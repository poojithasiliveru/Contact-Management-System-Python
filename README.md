# 📱 Contact Management System

A simple **console-based Contact Management System** developed using **Python and OOP concepts**.

## ✨ Features

* Add Contact
* Update Contact
* List Contacts
* Delete Contact
* Search Contact
* Add/Remove Favorite
* List Favorite Contacts
* Exit

## 🛠️ Technologies Used

* Python
* OOP
* Classes & Objects
* Lists
* Loops & Conditional Statements

## 📋 Sample Menu

```text
===== CONTACT MANAGEMENT SYSTEM =====

1. Add Contact
2. Update Contact
3. List Contacts
4. Delete Contact
5. Search Contact
6. Add/Remove Favorite
7. List Favorite Contacts
8. Exit
```

## ▶️ How to Run

```bash
python contact_management.py
```

Select an option from the menu and follow the instructions.
